Through this project, I learned the importance of organizing code so it is easier to understand, update, and reuse. In Project One, I created a CRUD Python module using PyMongo to perform database operations. I then used the same module in Project Two to connect the database to the Grazioso Salvare dashboard. This helped me understand the benefit of separating database operations from the rest of the application instead of writing everything in one place. In the future, I could reuse this module in other projects that need to store, retrieve, update, or delete data, with changes as needed for each project.

Working on the Grazioso Salvare project taught me to break down a problem into smaller steps. I started by working with the animal shelter database and creating queries to find dogs that matched the required search-and-rescue training profiles. I then connected the database to the dashboard so users could filter the records and view the results in a table, map, and chart. Compared to some of my previous assignments, this project required me to bring different parts together and make sure they worked correctly. If I work on a similar project in the future, I would start by understanding the client's requirements, plan how each part should work, and test the application as I build it.

Before working on this project, I understood that programming could solve problems, but this project helped me see how databases and applications can work together to make information more useful. The Grazioso Salvare dashboard allows users to filter animal shelter records and identify dogs that may be suitable for different types of search-and-rescue training. Instead of manually searching through a large amount of data, users can view relevant results in one place. This could save time and help trainers evaluate potential candidates more efficiently. Through this project, I learned that computer scientists do more than write code. They also develop tools that help people make better use of information and solve real-world problems.
